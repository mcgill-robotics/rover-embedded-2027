# Library UART Handler

This is an example library that relies on the STM32 HAL. 

The code for the library is in [`src`](./src/). In that folder there is a [`CMakeLists.txt`](./src/CMakeLists.txt) that defines helps define the library. Note that it includes `stm32cubemx` as it uses the STM32 HAL.

The [`CMakeLists.txt`](./CMakeLists.txt) in this folder is used to build the firmware that can be used to test the library. This was mostly generated by STM32CubeMX except for the code to import the library. The test code can be found in the [`Core`](./Core/) folder.

This library is a simple library to read from a UART peripheral and to buffer the data.
