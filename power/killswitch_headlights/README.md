# Killswitch/Headlights

Firmware for the Teensy controlling the Power Board

## About

This firmware allows killing the secondary system (Arm and Drive) on the power
board through the Teensy's USB connection. The headlights can also be toggled On and Off using this firmware. A companion script to control from the command line can be found at [here](../../bridge/src/rover_embedded/power/power_board_cli.py) in the `bridge` folder of this repo.
